## Waitlist Form

The homepage waitlist form submits to [Web3Forms](https://web3forms.com). It needs an access key at build time:

```bash
cp .env.local.sample .env.local
# Set NEXT_PUBLIC_WEB3FORMS_ACCESS_KEY to your Web3Forms access key
```

Create a free access key at https://web3forms.com by entering the email address that should receive waitlist signups. In production the key comes from the `WEB3FORMS_ACCESS_KEY` GitHub Actions secret used by `.github/workflows/deploy-website.yml`. Without a key the form renders but shows an error on submit.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
